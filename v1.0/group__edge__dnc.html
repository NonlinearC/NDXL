◆ NDXLEdgeCallback

typedef int(*) NDXLEdgeCallback(NDXLEdge *_Edge, double *_Y, double _Time, void *_Params)

Defines a user-supplied discrete callback that is invoked during simulation of the edge's host network.

Parameters
[in]_EdgeThe calling edge.
[in,out]_YFlat vector containing the most recently accepted state vector of the calling edge. Is guaranteed to have ndxlGetEdgeOrder(calling_edge) elements, and may be modified in-place.
[in]_TimeCurrent simulation time of the calling edge, equivalent to ndxlGetEdgeTime(calling_edge).
[in]_ParamsUser-defined parameters associated with the calling edge.
Returns
Integer indicating function success (zero) or failure (any nonzero value).
Note
If this function returns a nonzero value during simulation, NDXL terminates the simulation, and internally raises a NDXL_SIM_ERR.
Warning
Writing beyond ndxlGetEdgeOrder(calling_edge) elements to the state vector can result in out-of-bounds writes and undefined behaviour.

◆ NDXLEdgeDynamics

typedef int(*) NDXLEdgeDynamics(NDXLEdge *_Edge, double *_dY, const double *_Y, double _Time, void *_Params)

Defines a user-supplied function that governs how the state of a edge evolves over time.

Parameters
[in]_EdgeThe calling edge.
[out]_dYFlat output vector containing the time derivative of the calling edge. ndxlGetEdgeOrder(calling_edge) total elements must be written to it, even if those elements are zero.
[in]_YFlat input vector containing the current Runge-Kutta stage of the calling edge. Is guaranteed to have ndxlGetEdgeOrder(calling_edge) elements.
[in]_TimeLocal simulation time of the calling edge, offset by a fraction of the step size corresponding to the next Runge-Kutta stage. Note that this is generally NOT equivalent to ndxlGetEdgeTime(calling_edge), which only updates on a successful step.
[in]_ParamsUser-defined parameters associated with the calling edge.
Returns
Integer indicating function success (zero) or failure (any nonzero value).
Note
If this function returns a nonzero value during simulation, NDXL terminates the simulation, and internally raises a NDXL_SIM_ERR.
Warning
The function does not verify the number of elements written to the output array. Not writing to each element can result in garbage values or stale states being propagated. Writing beyond ndxlGetEdgeOrder(calling_edge) elements can result in out-of-bounds writes and undefined behaviour.
See also
ndxlGetEdgeOrder

◆ NDXLEdgeNoise

typedef int(*) NDXLEdgeNoise(NDXLEdge *_Edge, double *_dG, const double *_Y, double _Time, void *_Params)

Defines a user-supplied function that provides the amplitude of noise, for each element in its state vector, for each independent Wiener process the edge is driven by.

Parameters
[in]_EdgeThe calling edge.
[out]_dGFlat output matrix containing the noise amplitudes, where element ij (at index i * ndxlGetEdgeChannelCount(calling_edge) + j) represents the amplitude of the j-th Wiener process on the i-th state-vector element. ndxlGetEdgeOrder(calling_edge) x ndxlGetEdgeChannelCount(calling_edge) total elements must be written to it, even if those elements are zero.
[in]_YFlat input vector containing the current Runge-Kutta stage of the calling edge. Is guaranteed to have ndxlGetEdgeOrder(calling_edge) elements.
[in]_TimeLocal simulation time of the calling edge, offset by a fraction of the step size corresponding to the next Runge-Kutta stage. Note that this is generally NOT equivalent to ndxlGetEdgeTime(calling_edge), which only updates on a successful step.
[in]_ParamsUser-defined parameters associated with the calling edge.
Returns
Integer indicating function success (zero) or failure (any nonzero value).
Note
If this function returns a nonzero value during simulation, NDXL terminates the simulation, and internally raises a NDXL_SIM_ERR.
Warning
The function does not verify the number of elements written to the output array. Not writing to each element can result in garbage values or stale states being propagated. Writing beyond ndxlGetEdgeOrder(calling_edge) x ndxlGetEdgeChannelCount(calling_edge) elements can result in out-of-bounds writes and undefined behaviour.
