Detailed Description

Simulation Behaviour
Simulation starts at the local simulation time of a network i.e., the first simulation starts at t = 0, and subsequent simulations on the same network start at whatever time the previous simulation finished. Each network essentially functions as its own state machine, and because networks can dynamically change during simulation, only the current simulation state is preserved. Any errors encountered during simulation thus leave the network in the state it was in before the error occured. The evaluation order for a single Runge-Kutta stage is all vertices from ndxlGetNetworkFirstVertex to ndxlGetNetworkLastVertex, followed by all edges from ndxlGetNetworkFirstEdge to ndxlGetNetworkLastEdge.
Callback Invocation
Network callbacks are invoked once at local simulation time t = 0, before integration begins, and subsequently after every successful integration step. The initial callback is only invoked once during the lifetime of a network; repeated calls to simulation functions do not invoke it again. Agent callbacks are invoked after every successful integration step, but are not invoked at the initial simulation time. Like stepping, vertex callbacks are evaluated first, then edge callbacks, in the same order as described above.
External Failure
Any callback, dynamics, or noise function returning any nonzero value indicates failure. NDXL immediately terminates the simulation upon receiving this signal. The network state is not rolled back following a callback failure. Instead, it remains at the state reached when the callback was invoked, with all previously completed integration steps and the network configuration preserved.

const int ndxlNetworkSimulateDopri ( NDXLNetwork * _Network,
const double _Time,
const double _Atol,
const double _Rtol,
const double * _Tstops,
const size_t _Tcount,
NDXLNetworkCallback _Callback )
Parameters
[in]_NetworkTarget network to simulate.
[in]_TimeDuration of the simulation. Must be greater than zero.
[in]_AtolAbsolute tolerance (number of correct decimal places). Must be greater than zero.
[in]_RtolRelative tolerance (number of correct digits). Must be greater than zero.
[in]_TstopsArray containing times the solver must evaluate. May be 0, in which case _Tcount must also be 0.
[in]_TcountLength of _Tstops array. Must be greater than zero if _Tstops is provided, and 0 otherwise.
[in]_CallbackExternal discrete callback called once at local simulation time of 0, then again after each integration step. May be NULL.
Returns
Returns NDXL_OK if _Network is successfully integrated over _Time, otherwise returns NDXL_ERR.
Note
This method cannot be used if _Network contains stochastic agents as it is a purely deterministic method.
Warning
The function does not verify the capacity of the _Tstops array. Providing an inadequately sized array can result in out-of-bounds writes and undefined behaviour.
Errors raised
  • NDXL_ARG_ERR : _Network is NULL.
  • NDXL_VALUE_ERR : _Time <= 0.
  • NDXL_VALUE_ERR : _Atol <= 0.
  • NDXL_VALUE_ERR : _Rtol <= 0.
  • NDXL_VALUE_ERR : _Tstops is NULL and _Tcount is nonzero, or _Tstops is not NULL and _Tcount is 0.
  • NDXL_SIM_ERR : _Network contains no agents.
  • NDXL_SIM_ERR : _Network contains stochastic agents, one of the stochastic methods should be used.
  • NDXL_SIM_ERR : A dynamics, noise, or callback function returned a nonzero value during simulation.
